# Crimson Eclipse (Vampire Survivors-like)

A stylish browser-based survival arena game inspired by Vampire Survivors.

## Play locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173 in your browser.

## Controls

- `WASD` or Arrow Keys to move
- Attacks auto-fire at nearest enemy
- Collect blood orbs to level up
- Pick upgrades on each level

Survive as long as possible.
